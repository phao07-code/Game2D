## Luồng chơi nhanh để demo

1. Home → Bắt đầu → Cấp 1  
2. Hạ đủ lính → F mở 3 tù → Cổng Đông  
3. Lặp cấp 2 → Cấp 3 hạ Zorath → chọn Ending → **WIN**  
4. Cố chết → Game Over → Thống số / Màn đã chơi
